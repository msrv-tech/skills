# mxl — маршрутизатор MXL-макетов

Выбери и полностью выполни канонический skill:

| Задача | Skill |
|---|---|
| Создать MXL из JSON | `mxl-compile` |
| Получить JSON из MXL | `mxl-decompile` |
| Проанализировать MXL | `mxl-info` |
| Проверить MXL | `mxl-validate` |
| Добавить макет к объекту | `template-add` |
| Удалить макет из объекта | `template-remove` |

Спецификация DSL хранится только в `mxl-compile/docs/mxl-dsl-spec.md`; при декомпиляции используй её как каноническое описание формата.
