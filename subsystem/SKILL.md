# subsystem — маршрутизатор подсистем 1С

Выбери и полностью выполни канонический skill:

| Задача | Skill |
|---|---|
| Создать подсистему | `subsystem-compile` |
| Изменить состав или свойства | `subsystem-edit` |
| Проанализировать подсистему | `subsystem-info` |
| Проверить подсистему | `subsystem-validate` |
| Настроить командный интерфейс | `interface-edit` |
| Проверить командный интерфейс | `interface-validate` |

Справочник структуры командного интерфейса хранится только в `interface-edit/reference.md`.
