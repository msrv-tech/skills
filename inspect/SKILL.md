# inspect — маршрутизатор анализа объектов 1С

Определи тип входа и полностью выполни соответствующий skill:

| Объект | Skill |
|---|---|
| Конфигурация | `cf-info` |
| Расширение | `cfe-diff` |
| Объект метаданных | `meta-info` |
| Управляемая форма | `form-info` |
| Схема компоновки данных | `skd-info` |
| Табличный документ MXL | `mxl-info` |
| Роль | `role-info` |
| Подсистема | `subsystem-info` |

Для модификации используй соответствующий `edit`/`compile` skill, а для проверки — `validate`.
