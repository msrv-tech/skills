# epf — маршрутизатор внешних обработок

Не копируй реализацию и не ищи локальные скрипты в этом каталоге. Выбери и полностью выполни канонический skill:

| Задача | Skill |
|---|---|
| Создать исходники EPF | `epf-init` |
| Собрать EPF или ERF | `epf-build` |
| Разобрать EPF или ERF | `epf-dump` |
| Проверить XML EPF или ERF | `epf-validate` |
| Добавить управляемую форму | `form-add` |
| Добавить или удалить макет | `template-add` / `template-remove` |
| Добавить регистрацию БСП | `epf-bsp-init` |
| Добавить команду БСП | `epf-bsp-add-command` |

Если операция обращается к информационной базе, применяй также `test-databases`.
