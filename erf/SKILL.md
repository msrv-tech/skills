# erf — маршрутизатор внешних отчётов

Выбери и полностью выполни канонический skill:

| Задача | Skill |
|---|---|
| Создать исходники ERF | `erf-init` |
| Собрать ERF | `epf-build` |
| Разобрать ERF | `epf-dump` |
| Проверить XML ERF | `epf-validate` |
| Добавить управляемую форму | `form-add` |
| Добавить или удалить макет | `template-add` / `template-remove` |
| Изменить СКД | `skd-edit` |

`epf-build`, `epf-dump` и `epf-validate` намеренно являются общими для EPF и ERF. Если операция обращается к информационной базе, применяй также `test-databases`.
