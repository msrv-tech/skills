# validate — маршрутизатор валидаторов 1С

Определи тип входа и полностью выполни канонический skill:

| Объект | Skill |
|---|---|
| Конфигурация | `cf-validate` |
| Расширение | `cfe-validate` |
| Объект метаданных | `meta-validate` |
| Управляемая форма | `form-validate` |
| Подсистема | `subsystem-validate` |
| Командный интерфейс | `interface-validate` |
| Роль | `role-validate` |
| СКД | `skd-validate` |
| MXL | `mxl-validate` |
| EPF или ERF | `epf-validate` |

Не дублируй проверки в этом маршрутизаторе. После `compile`/`edit` учитывай встроенную валидацию выбранного специализированного skill.
