# db-list — вспомогательные настройки проекта 1С

`.v8-project.json` не является источником строк подключения, пользователей или паролей. Для любой операции с информационной базой сначала полностью выполни `test-databases` и выбери запись из его приватного реестра.

## Допустимые поля

```json
{
  "v8path": "<platform-bin>",
  "configSrc": "<project-root>/src",
  "webUrl": "http://localhost/example",
  "aliases": ["demo"],
  "branches": ["develop", "feature/*"]
}
```

- `v8path` — предпочтительная версия платформы для проекта;
- `configSrc` — каталог XML-исходников;
- `webUrl` — URL уже разрешённой веб-публикации;
- `aliases` и `branches` — подсказки для сопоставления проекта с записью `test-databases`.

Не сохраняй здесь `path` файловой ИБ, `server`, `ref`, строку подключения, пользователя или пароль. Если они уже есть, не используй и предложи перенести запись в приватный `test-databases.json`, после чего удалить секреты из проекта.

## Операции

- показать текущие вспомогательные настройки;
- добавить или изменить допустимое поле;
- удалить устаревшее вспомогательное поле;
- проверить, что файл не содержит параметров подключения и секретов.

Перед изменением покажи точный diff. Не создавай `.v8-project.json`, если задача не требует проектных настроек.
