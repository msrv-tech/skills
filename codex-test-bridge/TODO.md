Текущая доказательная база версии `0.7.0`: 49 публичных действий bridge,
62 обязательных варианта и 185 нативных шагов проходят на Linux/Xvfb с
платформой 1С `8.5.1.1150`. Этот список относится только к возможностям,
которых ещё нет в UI DSL bridge или для которых пока нет отдельного нативного

## Правило готовности

Пункт считается закрытым только когда одновременно выполнены все условия:

1. действие и варианты описаны в `ui-actions.matrix.json` и JSON Schema;
2. BSL dispatcher не содержит конфигурационных ad-hoc веток;
3. fixture использует реальный элемент управляемой формы 1С;
4. conformance-сценарий проверяет не только отсутствие исключения, но и
   наблюдаемый результат действия;
5. unit-тесты, `scripts/run_ui_conformance.py --validate-only` и нативный
   прогон поддерживаемого backend проходят;
6. документация и capabilities обновлены вместе с кодом.
