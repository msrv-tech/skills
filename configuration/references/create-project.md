# create-project — Создание конфигурации с нуля

Workflow-скил: оркестрирует полный цикл создания конфигурации 1С от scaffold до валидации.

## Цепочка навыков

```
/configuration:create-empty           → scaffold пустой конфигурации
      ↓
/metadata:create ×N   → создать все объекты метаданных
      ↓
/access-and-navigation:subsystem-create → создать подсистемы, включить объекты
      ↓
/access-and-navigation:role-create      → создать роли с правами на объекты
      ↓
/forms:add ×N       → создать формы объектов
/forms:create ×N   → скомпилировать формы
      ↓
/configuration:validate       → финальная проверка
```

## Алгоритм

1. **Собрать требования**: имя конфигурации, список объектов, структура подсистем, роли
2. **Scaffold конфигурации** (`/configuration:create-empty`): имя, синоним, версия
3. **Создать объекты** (`/metadata:create` для каждого): справочники, документы, регистры, модули; каждый объект автоматически регистрируется в `Configuration.xml`
4. **Создать подсистемы** (`/access-and-navigation:subsystem-create`): дерево подсистем, распределить объекты
5. **Создать роли** (`/access-and-navigation:role-create`): права доступа к объектам
6. **Создать формы** (`/forms:add` + `/forms:create`): для объектов с UI
7. **Валидация** (`/configuration:validate`): проверить всю конфигурацию

## Пример использования

```
> Создай конфигурацию "УчётЗаявок" с:
  - Справочник Клиенты (Наименование, ИНН, Телефон)
  - Документ Заявка (Клиент, Дата, Сумма, ТЧ Товары)
  - Регистр накопления ОстаткиТоваров
  - Подсистема Основная
  - Роль Администратор (полные права)
```

## Важно

- Порядок создания: сначала справочники (на них ссылаются документы), потом документы, потом регистры
- Для документов с движениями — создать регистры до документов (нужны для RegisterRecords)
- Всегда завершать `/configuration:validate`
