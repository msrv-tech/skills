# add-object — Добавление объекта в конфигурацию

Workflow-скил: оркестрирует цепочку навыков для полного добавления объекта метаданных.

## Цепочка навыков

```
/metadata:create  → создать XML-исходники объекта и зарегистрировать в Configuration.xml
      ↓
/access-and-navigation:subsystem-edit → добавить объект в подсистему (видимость в интерфейсе)
      ↓
/forms:add      → создать scaffold формы для объекта
      ↓
/forms:create  → скомпилировать форму из JSON DSL
      ↓
/metadata:validate → проверить объект
/configuration:validate   → проверить конфигурацию
```

## Алгоритм

1. **Определить параметры**: тип объекта, имя, реквизиты, табличные части, подсистема
2. **Создать объект** (`/metadata:create`): передать JSON с описанием реквизитов и ТЧ; скрипт сам регистрирует объект в `Configuration.xml`
3. **Добавить в подсистему** (`/access-and-navigation:subsystem-edit`): `-Operation add-content -Value "<Type>.<Name>"`
4. **Создать форму** (`/forms:add`): scaffold управляемой формы
5. **Скомпилировать форму** (`/forms:create`): JSON DSL с элементами
6. **Валидация** (`/metadata:validate`, `/configuration:validate`): проверить корректность

## Пример использования

```
> Добавь справочник Контрагенты с реквизитами ИНН (строка 12), КПП (строка 9),
  табличная часть КонтактныеЛица (ФИО, Телефон, Email).
  Конфигурация в src/, подсистема Основная.
```

## Важно

- Если подсистема не указана — спросить пользователя
- Если форма не нужна (общий модуль, перечисление) — пропустить шаги forms:add/forms:create
- Всегда завершать валидацией
