# Демонстрационные UI-тесты

- `01-connect.ui.json` — минимальный smoke штатного соединения TestManager/TestClient.
- `02-counterparties-inspect.ui.json` — диагностический сценарий прямой навигации. На исходной демобазе БП он выявляет блокирующие стартовые формы и прикладные ограничения пользователя; используйте его после настройки тестового пользователя и стартового состояния.
- `03-main-dashboard.ui.json` — успешно проверенный read-only сценарий: безопасный стартовый диалог, поиск информационной панели и получение семантического дерева.
- `run-demo.ps1` — запуск выбранного сценария через приватный `test-databases.json` без хранения стендовых подключений в репозитории.
