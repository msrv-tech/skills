# external-artifacts:epf-full-cycle — Полный цикл создания обработки

Workflow-скил: оркестрирует цепочку навыков для создания внешней обработки от scaffold до EPF-файла.

## Цепочка навыков

```
/external-artifacts:epf-create       → scaffold пустой обработки (XML-исходники)
      ↓
/forms:add      → добавить управляемую форму
      ↓
/forms:create   → скомпилировать форму из JSON DSL
      ↓
/layouts:attach   → добавить макеты (если нужны печатные формы)
      ↓
/layouts:mxl-create    → скомпилировать макеты из JSON DSL
      ↓
/1c-bsp-registration   → регистрация БСП (если дополнительная обработка)
      ↓
/1c-bsp-command → добавить команды БСП (если нужно)
      ↓
/external-artifacts:validate   → проверить корректность
      ↓
/external-artifacts:build      → собрать EPF-файл
```

## Алгоритм

1. **Определить параметры**: имя обработки, назначение, реквизиты, формы, макеты, БСП
2. **Scaffold** (`/external-artifacts:epf-create`): создать XML-исходники пустой обработки
3. **Форма** (`/forms:add` + `/forms:create`): создать и скомпилировать форму
4. **Макеты** (`/layouts:attach` + `/layouts:mxl-create`): если нужны печатные формы
5. **БСП** (`/1c-bsp-registration` + `/1c-bsp-command`): если дополнительная обработка/отчёт
6. **Модуль формы**: написать BSL-код обработчиков
7. **Валидация** (`/external-artifacts:validate`): проверить XML-структуру
8. **Сборка** (`/external-artifacts:build`): собрать EPF-файл (требует платформу 1С)

## Пример использования

```
> Создай обработку "ЗагрузкаПрайса" с формой:
  - Поле выбора файла, кнопка "Загрузить"
  - Таблица предпросмотра данных
  - Зарегистрировать как доп. обработку БСП
  - Собрать EPF в build/
```

## Важно

- Шаг сборки (`/external-artifacts:build`) требует установленную платформу 1С
- БСП-регистрация нужна только для обработок, подключаемых через "Дополнительные отчёты и обработки"
- Макеты нужны только при наличии печатных форм
- Модуль объекта пишется вручную (или через Edit), не через навык
